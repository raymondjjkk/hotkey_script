# Gemini 极速上传与全能效率增强 AHK 脚本使用手册

本文档为基于 AutoHotkey v2 编写的全局效率脚本说明书。该脚本集成了智能剪贴板监听、Gemini 极速传图、多击按键触发、划词自动复制等一系列硬核极客功能。

---

## Ⅰ. 核心工作流：Gemini 极速传图 (Vimium 版)

此功能实现了从“截图”到“上传提问”的无缝闭环，搭配 Chrome 插件 Vimium 实现了毫秒级焦点抢占。

* **智能监听**：当系统剪贴板中出现图片时，屏幕中央会自动弹出一个精致的 Gemini 悬浮窗。
* **自动隐藏**：悬浮窗存在 **5 秒**后若无操作将自动隐藏，不打扰日常工作。按 `Esc` 键也可立即隐藏。
* **三重触发方式**（触发后自动唤醒/打开最近使用的 Gemini 窗口，利用 Vimium 的 `gi` 定位输入框，粘贴并回车发送）：
1. **鼠标点击**：直接点击屏幕中央的 Gemini 悬浮图标。
2. **快捷键组合**：按下 `Win + Shift + G` (`#+g`)。
3. **键盘连击（沉浸式）**：在任意输入状态下，连续按下 **4 次 `g**` 键。系统会自动执行 4 次退格擦除多余的 `g` 字符，并瞬间触发图片上传。

## Ⅱ. 连击触发器 (Multi-Tap Actions)

通过极速连按特定按键，触发快捷指令，并在执行前自动擦除输入框中因连击产生的多余字符。

| 触发动作 | 按键组合 | 执行效果 |
| --- | --- | --- |
| **Alt 键** | 连按 3 次 (左/右 Alt) | 模拟 `Ctrl + V` 极速粘贴，并弹出提示。 |
| **Space 键** | 连按 4 次 | 擦除多余空格，并触发 `Ctrl+Shift+7` 热键。 |
| **`n` 键** | 连按 5 次 | 擦除字符，快速启动 **记事本 (Notepad)**。 |
| **`z` 键** | 连按 3 次 | 擦除字符，快速启动 **知乎**。 |
| **`r` 键** | 连按 3 次 | 擦除字符，快速启动 **Reddit**。 |
| **`y` 键** | 连按 3 次 | 擦除字符，快速启动 **YouTube**。 |
| **`e` 键** | 连按 3 次 | 擦除字符，快速启动 **Everything** 搜索。 |
| **`a` 键** | 连按 3 次 | 擦除字符，快速启动 **Anytxt Searcher**。 |
| **`g` 键** | 连按 4 次 | 擦除字符，触发 **Gemini 图片上传**（详见第一节）。 |

## Ⅲ. 快捷启动台 (App Launchers)

使用反引号 **```** (键盘左上角 Esc 下方按键) 作为前置修饰键，组合数字或字母实现秒级程序启动。

### 数字区组合

* `` + 1`：启动 Google Chrome
* `` + 2`：启动 Gemini (Chrome App)
* `` + 3`：启动 WPS 听记
* `` + 4`：启动 Bilibili
* `` + 5`：启动 YouTube
* `` + 6`：启动 Youglish
* `` + 7`：启动 抖音
* `` + 8`：启动 Telegram
* `` + 9`：执行 30秒后重启 (Restart BAT)
* `` + 0`：执行 30秒后关机 (Shutdown BAT)

### 字母区组合

* `` + n`：切换以太网卡状态 (Toggle Ethernet)
* `` + g`：启动 ScreenToGif 录屏工具

> **核心修复说明**：为了防止反引号 ``` 被完全占用，脚本已实现按一下 ``` 输出原字符 ```，按 `Shift + `` ` 输出波浪线 `~`。

## Ⅳ. 鼠标与剪贴板增强

### 1. 终极防冲突划词复制

* **功能**：用鼠标左键拖拽选中文本（X轴>35像素或Y轴>45像素，耗时80ms-1500ms），松开左键后系统自动执行 `Ctrl+C`。
* **防冲突机制**：
* 智能拦截截图软件的干扰（Snipaste, SnippingTool, PixPin 等）。
* 自动识别光标状态，当光标为**十字准星 (Cross)** 时不触发。
* 保护剪贴板中的图片数据，绝不会因为误划空白处而用空文本覆盖已有的图片。



### 2. 鼠标右键极速粘贴

* **功能**：在 450 毫秒内，连续点击 **3 次鼠标右键**，将自动触发粘贴 (`Ctrl+V`)，随后发送 `Esc` 关闭可能弹出的右键菜单。

## Ⅴ. 实用辅助模块

### 1. 记事本静默自动保存 (Windows 11)

针对系统原生 Notepad 的增强，后台每 3 秒检测一次：

* 当焦点在记事本且标题栏带有未保存标志（`*` 或 `•`）时。
* 当键盘空闲超过 2 秒且未按下组合键时。
* 系统会在后台静默发送保存指令 (`Ctrl+S`)，并在鼠标处弹出短暂提示。

### 2. 开发级热重载

在代码编辑器中修改此 AHK 脚本并按下 `Ctrl+S` 保存时，脚本会延迟 200ms 等待磁盘写入，随后**自动重新加载并应用最新代码**，无需手动重启。

### 3. F 区与导航键基础重映射

* `F1`：撤销 (`Ctrl+Z`)
* `F3`：粘贴 (`Ctrl+V`)
* `F4`：复制 (`Ctrl+C`)
* `F5`：全选 (`Ctrl+A`)
* `F6`：关闭/退出 (`Alt+Q`)
* `F8`：`Ctrl+Shift+8`
* `F9`：`Ctrl+Shift+9`
* `F10`：`Ctrl+Shift+P`
* `F11`：关闭标签页 (`Ctrl+W`)
* `F12`：`Ctrl+Shift+Esc` (通常用于调出任务管理器)
* `End`：`Win+Shift+Right` (通常用于跨显示器移动窗口)
* `PgUp`：`Ctrl+Enter`
* `PgDn`：粘贴 (`Ctrl+V`)

## Ⅵ. 环境与依赖要求

1. **AutoHotkey 版本**：必须使用 AutoHotkey v2.0 及以上版本运行。
2. **浏览器要求**：需在 Chrome 浏览器中安装并启用 **Vimium** 扩展插件（因为脚本依赖其 `gi` 快捷键来重置输入框焦点）。
3. **路径有效性**：首次部署或迁移环境时，需确保第 10-12 行的 `geminiLnkPath` 和 `iconPath` 变量，以及第 64-83 行的各个快捷方式路径真实存在于你的计算机上，否则使用相关启动键时会弹出找不到文件的提示。
